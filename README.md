# 快艇骰子 最优决策求解器

《世界游戏大全 51》里的快艇骰子（Yahtzee）——**精确动态规划求解器**，不是启发式。
给定牌面和记分卡，它算出每一步的最优保留；给定双方记分卡，它算出你的胜率。

第一局战绩：**197 : 188 胜**（最优策略期望 191.8，实际超出 5.2 分）。

---

## 这版规则（和标准 Yahtzee 不同，代码按这个建模）

| 栏位 | 计分 |
|---|---|
| 1点 ~ 6点 | 对应点数 × 个数 |
| **四条** | 五颗骰子点数总和（≥4 颗相同；五颗相同也算） |
| **葫芦** | 五颗骰子点数总和（3+2 或五颗相同） |
| 小顺 | **15** |
| 大顺 | **30** |
| 快艇 | **50** |
| 机会 | 五颗骰子总和 |
| 上区奖励 | 前六栏合计 **≥ 63 加 35 分** |

共 12 栏（**没有「三条」**）。大顺也算小顺，快艇也算四条/葫芦。

## 用法

所有命令都在本目录下跑。懒得打 `./.venv/bin/python` 的话，先 `source .venv/bin/activate`。

### 1. 开新局

```bash
./.venv/bin/python advise.py reset
```

### 2. 每掷一次骰子，问保留

```bash
./.venv/bin/python advise.py adv "1 3 3 3 4" 2
```

第二个参数是**剩余重投次数**：刚掷完第一次给 `2`，第二次给 `1`，第三次（该记分了）给 `0`。

输出会列出最优保留、期望总分，以及次选方案差多少分。

### 3. 记分

```bash
./.venv/bin/python advise.py take 3点 "1 2 3 3 3"
```

分数由骰子自动算出，同时更新上区进度和剩余最优期望。

### 4. 看当前记分卡

```bash
./.venv/bin/python advise.py show
```

### 5. 算胜率

```bash
./.venv/bin/python pwin.py 8 6000 "1点=2,2点=8,3点=12,机会=22"
```

- 参数 1：你剩余回合数（= 你未填的栏数）
- 参数 2：蒙特卡洛样本数（默认 3000；6000 约 3 秒，误差 ±0.6%）
- 参数 3：**对方的完整记分卡**，格式 `栏位=分,栏位=分`；全空就传 `""`

我方的记分卡从 `state.json` 读。

**注意口径**：如果你刚打完这一回合、对方还没掷，那么「你剩 N 回合、对方剩 N+1 回合」，
算出来的胜率会**偏保守**。等对方也掷完，两边才在同一基准上。

## 文件

| 文件 | 作用 |
|---|---|
| `solve.py` | 构建 DP 表（约 4 秒，17.6 万个状态），输出 `tables.npz` + `meta.json` |
| `advise.py` | 决策引擎 + 记分卡管理 + 全盘蒙特卡洛验证 |
| `pwin.py` | 胜率引擎（双方独立采样 + 终局比较） |
| `verify2.py` | 任意中间局面的蒙特卡洛校验 |
| `debug.py` | 分区校验（上区单练 / 下区单练） |
| `state.json` | 当前局的记分卡（`reset` 清空） |
| `results/` | 打完的局存档 |

`tables.npz` 已随仓库提供。规则若有改动，改 `solve.py` 里的 `SC` 计分矩阵后重跑即可。

## 它算得准吗

DP 的数值全部经过独立蒙特卡洛校验（模拟用真实随机骰子 + 独立算分路径）：

| 校验项 | DP | 模拟 |
|---|---|---|
| 全局期望（12 栏全开） | 191.774 | 191.540 ± 0.342 |
| 上区单练（6 栏） | 71.952 | 72.027 ± 0.387 |
| 下区单练（6 栏） | 88.660 | 88.954 ± 0.410 |
| 中间局面 `6点差7分+小顺+快艇` | 64.32 | 64.26 ± 0.12 |
| 中间局面 `葫芦+小顺+快艇`（奖励已锁） | 61.78 | 61.73 ± 0.11 |
| 对称开局胜率（理论 49.6%） | — | 49.53% |
| 某残局胜率（手算 2.97%） | — | 2.88% |

随时可以复跑：

```bash
./.venv/bin/python advise.py sim 20000   # 全盘模拟对照
./.venv/bin/python verify2.py            # 中间局面校验
```

## 已验证的两个反直觉结论

**1. 别拿高价值栏位换便宜分。**
`1 2 4 6 6` 这手牌里，「记 6点 = 12 分」比「记 1点 = 1 分」**差 10 分期望**。
因为 6点 是上区最大的一块（上限 30），把它花在 12 分上会让 +35 奖励的概率从
**54.2% 崩到 12.1%**。同理：`4 4 4 4 1` 该记 4点 = 16（不是四条 = 17），
`4 6 6 6 6` 该记四条 = 28（不是机会 = 28，差 15.1 分）。

**2. 该放弃的栏位要趁早放弃。**
`2 4 4 6 6` 硬追大顺成功率只有 16%，不如把这一掷用来把机会栏做大（约 24 分），
下一回合再从零打大顺（成功率 26%，反而更高）。

模型假设**双方都按期望分最大化**打。对手乱打的话，你的实际胜率会高于算出来的数字。
